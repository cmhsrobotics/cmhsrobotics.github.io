# ElectoMagnets website

Jekyll site for the ElectoMagnets FIRST Tech Challenge team.

- Run locally: `bundle install && bundle exec jekyll serve`
- Site settings: `_config.yml`
- Page content: `about.md`, `team.md`, `results.md`, `outreach.md`
- Structured data (members, results, outreach): `_data/*.yml`
- Styles: `assets/css/style.css`
